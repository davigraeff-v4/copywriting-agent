# Exemplo de Briefing — Incompleto

Exemplo de briefing típico de gestor apressado — sem persona, sem restrições, sem referência. Use como referência do que a skill `02-briefing-diagnosis` deve detectar como lacuna crítica vs. inferível.

```
Doc de copy: Campanha de aniversário da loja
Descrição da campanha e estratégia: Queremos divulgar o aniversário de 5 anos da loja
  com desconto especial
Quantidade de designs: 3
Tipo do criativo: Estático
Formato do criativo: Feed
Canal de tráfego: Instagram e Google
Objetivo: Vender mais durante a semana do aniversário
Público-alvo: Clientes da loja
Persona: (não preenchido)
Referência visual obrigatória: (não preenchido)
Restrições para o time criativo: (não preenchido)
Instagram: instagram.com/lojaexemplo
Site: (não preenchido)
LP: (não preenchido)
ID visual: (não preenchido)
Pasta do Drive: (não preenchido)
Notion: (não preenchido)
```

## Como o Copywriting Agent deve reagir

- **Crítico, pergunte:** canal está ambíguo ("Instagram e Google" — dois canais com formatos diferentes, precisa saber prioridade); objetivo é vago ("vender mais" — vender o quê, ticket médio, meta?); referência visual ausente.
- **Pode inferir com hipótese:** persona (a partir de "clientes da loja" + segmento do negócio, se conhecido via `clients/{cliente}.md`); tom de voz.
- **Não bloqueia:** falta de Notion/Drive/ID visual — são apoio, não crítico para produção de copy.
