## 2. Diagnóstico por critérios

| Critério | Reflexão / análise |
|---|---|
| Clareza da proposta | Está claro o que está sendo vendido ou comunicado? |
| Aderência ao público-alvo | A copy/visual fala com dores e desejos reais? Está no tom certo para o nível de consciência? |
| Headline / título principal | Atrai atenção? Gera curiosidade? É específico e impactante? |
| Subheadline / complemento | Reforça o título? Aumenta clareza ou desejo? |
| Copy longa (legenda, corpo do anúncio, LP) | Segue estrutura lógica? Tem fluidez e ritmo? Explora prova, dor, benefício? |
| Call to Action (CTA) | Claro, direto e conectado com o objetivo da campanha? |
| Copy + arte (coerência visual) | O criativo e a copy estão bem integrados? Um reforça o outro? |
| Tom de voz e branding | Fiel à identidade da marca? Alinhado com o que foi definido no manual de comunicação/`clients/{cliente}.md`? |
| Originalidade / repertório criativo | Algo novo, relevante ou memorável foi usado? |
| Resultado (se disponível) | CTR, CPC, conversão ou feedback qualitativo do cliente? |

## 3. Diagnóstico final

```
Pontos fortes da campanha: (ex.: copy emocional bem alinhada ao criativo; uso inteligente de escassez)
Pontos fracos / oportunidades de melhoria: (ex.: head genérica; copy longa sem ritmo)
```

## 5. Notas por pontuação (1 a 5, opcional — acompanhar evolução ao longo das semanas)

Clareza · Persuasão · Alinhamento ao público · Originalidade/impacto · Coesão copy+design · Potencial de conversão.

## Como usar na THAMY IA

- Rodar este template quando o gestor pedir para revisar uma campanha **já publicada** (não uma copy nova ainda não entregue — para isso, use `quality/scorecard.md` via `13-copy-review-scorecard`).
- Registrar "Insight replicável para outros clientes" em `clients/{cliente}.md` como aprendizado, e considerar se vale adicionar a `knowledge/banco-de-angulos.md` ou `knowledge/erros-comuns.md`.
