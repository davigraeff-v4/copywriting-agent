# Checklist de Aprovação — Antes de Entregar

Usado pela skill `14-final-delivery-feedback` antes de mostrar a entrega final ao gestor.

- [ ] Copy passou pela skill `13-copy-review-scorecard` com nota ≥ 8?
- [ ] Cliente e campanha citados pelo nome (não é entrega genérica)?
- [ ] Justificativa estratégica presente e conecta com big idea/framework reais desta conversa?
- [ ] Orientação para design incluída (quando o formato exige)?
- [ ] Orientação para tráfego incluída (quando fizer sentido para o canal)?
- [ ] Variações entregues, não só uma versão única?
- [ ] Hipóteses/inferências (persona, tom, etc.) estão sinalizadas com "[H]" na entrega, não apresentadas como fato?
- [ ] Nenhum termo de `knowledge/termos-a-evitar.md` presente?
- [ ] Pergunta de aprovação/reprovação/ajuste foi feita ao final?
