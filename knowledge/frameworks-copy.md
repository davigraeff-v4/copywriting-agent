# Frameworks de Copy

> Fonte: síntese de 6 pins de referência (Justin Welsh, Agiclik, Agência Ela Cria, Single Grain, Chase Dimond) + framework-base do PRD. Usado pela skill `10-framework-trigger-selector` e `11-copy-production`. Ver também `knowledge/processo-de-copy.md` (etapa de "ideação" onde o framework é escolhido) e `knowledge/gatilhos-psicologicos.md` (o "porquê" por trás de cada framework).

## Frameworks principais

| Sigla | Passos | Melhor para |
|---|---|---|
| **AIDA** | Atenção → Interesse → Desejo → Ação | Posts de redes sociais, anúncios curtos |
| **PAS** | Problema → Agitação → Solução | Qualquer copy curta, anúncios |
| **PASO** | Problem → Agitate → Solution → Outcome | Variação do PAS com resultado explícito |
| **BAB** | Before → After → Bridge | Transformação, antes/depois |
| **4Us** | Urgente, Único, Útil, Ultra-específico | Headlines e CTAs |
| **PASTOR** | Pain → Amplify → Story → Transformation → Offer → Response | Posts/e-mails de lançamento, copy longa |
| **QUEST** | Qualify → Understand → Educate → Stimulate → Transition | E-mails e vendas consultivas |
| **PAPA** | Problem → Advantages → Proof → Action | Vendas com prova |
| **ACE** | Attention → Content (valioso) → Engage (CTA) | Conteúdo educativo com CTA |
| **HERO** | Hook → Engage (história) → Reveal (produto) → Offer | Anúncios/copy de scroll rápido |
| **SLAP** | Stop → Look → Action → Purchase | Anúncios muito curtos |
| **Storytelling** | Situação → Conflito → Resolução | Conexão emocional, cases |
| **Punchline / One Liner** | Uma frase que carrega toda a mensagem | Headlines de alto impacto |
| **Jobs To Be Done** | Copy organizada em torno do "trabalho" que o público quer resolver | Qualquer copy — é a lente por trás de todos os frameworks acima |

**Leitura comparativa:** praticamente todos os frameworks seguem a mesma espinha dorsal — **problema → prova/agitação → solução → ação** — variando só em quantos passos intermediários adicionam. HERO e SLAP são os mais curtos (scroll rápido); QUEST e PASTOR são mais longos (e-mails, vendas consultivas).

## AIDA aplicado por estado mental do cliente (Single Grain)

Força pensar no estado do cliente antes de escolher o tipo de conteúdo — é diagnóstico de funil, não só checklist de escrita:

| Etapa | Estado do cliente | Conteúdo necessário |
|---|---|---|
| Attention | Sente a dor mas não reconhece o problema específico | Conteúdo que nomeia o problema |
| Interest | Quer informação que ajude a resolver | Conteúdo informativo que avança a fase |
| Desire | Deseja a solução e avalia alternativas | Conteúdo que convence que sua solução é a certa |
| Action | Quer decidir a compra | CTA forte e caminho simples até a venda |

## PASTOR aplicado (exemplo real anotado — Justin Welsh)

1. **Pain** — nomeie a dor específica ("se você já teve dificuldade para criar conteúdo que converte, você não está sozinho").
2. **Amplify** — liste consequências da dor não resolvida (tempo perdido, oportunidades perdidas).
3. **Story** — como você (ou alguém) encontrou um método comprovado.
4. **Transformation** — o resultado de usar o método.
5. **Offer** — a solução com benefícios concretos.
6. **Response** — CTA explícito.

Cada bloco = um parágrafo separado. Serve de guia de *pacing*: parágrafos curtos, uma ideia por bloco.

## Seis estruturas de storytelling

| Estrutura | Passos |
|---|---|
| Treinamento | Situação comum → Ação realizada → Virada de chave |
| Pergunta Reflexiva | Questão provocadora → História que exemplifica → Conclusão |
| O 3 Passos | Contexto → Conflito ("mas") → Desfecho |
| Comparação | Expõe duas soluções → Avalia prós/contras → Conclui qual é ideal para cada perfil |
| Antes e Depois | O que você vivia → O que mudou → Insight final |
| Problema e Solução | Problema concreto → Solução eficaz → CTA |

Use como "moldura" narrativa dentro de qualquer framework acima (ex.: o "Story" do PASTOR pode seguir a estrutura "Antes e Depois").

## Critério de escolha (skill `10-framework-trigger-selector`)

Na ordem de peso: objetivo da campanha → etapa do funil → persona → canal → nível de consciência → tipo de oferta.
