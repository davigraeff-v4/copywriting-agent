## Template real — Meta Ads (Criativo estático e Carrossel)

Convenção V4: sempre testar variações A/B (mesma peça, copy diferente) e listar 3 combinações de texto principal + título prontas "para uso do gestor" de tráfego.

### Criativo estático (Feed & Story)

```
Criativo A | Persona x
Head:
Subhead:
CTA:

Criativo B | Persona x  (para teste A/B do mesmo criativo, só mudando a copy — excluir se não usar)

PARA USO DO GESTOR:
Texto principal A [legenda → recomendação: 125 caracteres] / Título A [recomendação: 40 caracteres]
Texto principal B [...] / Título B [...]
Texto principal C [...] / Título C [...]
```

### Carrossel

```
Criativo A | Persona x
Dobra 1 — Head: / Subhead: / CTA:
Dobra 2 — Corpo:
Dobra 3 — Corpo:
Dobra 4 — Corpo:
Dobra 5 — Corpo:

PARA USO DO GESTOR: (mesma lógica de 3 variações A/B/C do estático)
```

### Exemplo real preenchido — cliente C-Eleven (Instituto Cliente Feliz, mentoria de CX)

Três variações completas de criativo estático para o mesmo produto, cada uma com ângulo diferente — bom exemplo de como variar o gancho mantendo a mesma oferta:

**Variação 1 (ângulo: reposicionar CX como lucro, não custo)**
- Head: "CX não é só 'atendimento humanizado'. É estratégia de lucro e retenção."
- Subhead: "Pare de tratar a experiência do cliente como um custo operacional e comece a enxergá-la como um motor de crescimento e lucro para a sua empresa."
- CTA: "QUERO ESTRUTURAR MEU CX PARA LUCRAR."

**Variação 2 (ângulo: implementação lado a lado, não teoria)**
- Head: "Aqui, CX não é teoria. É implementação lado a lado"
- Subhead: "Em apenas 16 semanas, implementamos um sistema de Retenção, Evolução e Indicação, aplicado à realidade da sua empresa."
- CTA: "VER PROGRAMA COMPLETO"

**Variação 3 (ângulo: provocação — "seu CX está evoluindo ou só respondendo tickets?")**
- Head: "O mercado de CX mudou. Sua empresa está evoluindo ou apenas 'respondendo tickets'?"
- Subhead: "Implemente as metodologias mais atuais de Customer Experience e Customer Success com quem dita as tendências do setor no Brasil."
- CTA: "QUERO ATUALIZAR MINHA OPERAÇÃO."

**Textos principais (para uso do gestor de tráfego) — repetidos com pequenas variações nas 3 peças:**
- "CX não é custo, é lucro! Implemente o sistema de retenção e evolução que transforma clientes em motor de crescimento." / Título: "Transforme clientes em lucro real." ou "Gestão de CX que gera receita."
- "Chega de mentorias teóricas. No C-Eleven, nossos especialistas implementam seu CX lado a lado com você." / Título: "Mais lucro com Gisele e ICF."
- "A metodologia de quem fundou o ReclameAQUI, aplicada diretamente no seu negócio." / Título: "Escala e Lucratividade com CX."

**Leitura estratégica:** as 3 headlines usam ângulos diferentes sobre a mesma oferta (reposicionamento conceitual → prova de execução → provocação/pergunta), mas os 3 textos principais e títulos de apoio se repetem e se recombinam entre as peças — mostra que o "banco de blocos" (headline, subhead, CTA, texto de apoio) pode ser remontado em múltiplas combinações a partir de um punhado de variações bem feitas. Esse é o padrão que `11-copy-production` e `14-final-delivery-feedback` devem seguir ao entregar variações.

## Template real — Landing Page

Estrutura mais enxuta que o modelo genérico de `regras-por-canal.md` — é o que a V4 usa por padrão, ajustar conforme o objetivo da campanha (nem toda seção é obrigatória):

```
1ª seção | Header
Head / PUV:
Subline:
CTA:

(opcional) Formulário
Título: / Formulário: / CTA:

(opcional) Pop-up pós-formulário
Título:

2ª seção | Benefícios
Título:
Benefício 1 — Título: / Corpo:
Benefício 2 — Título: / Corpo:
Benefício 3 — Título: / Corpo:
Benefício 4 — Título: / Corpo:

3ª seção | Promessas
Título: / Corpo: / CTA:

4ª seção | Bônus / Oferta / Escassez
Título: / Corpo: / CTA:

5ª seção | Promessas (segunda leva, se aplicável)
Título: / Corpo: / CTA:

6ª seção | Prova social
Título: / Corpo: / CTA:
```

**Nota importante da V4:** "cada cliente e cada campanha tem objetivos diferentes e os campos devem ser moldados de acordo com isso, incluindo ou retirando seções" — não é uma estrutura rígida de 6 blocos obrigatórios, é uma base a adaptar. A skill `12-channel-format-adapter` deve seguir esse espírito: usar como ponto de partida, não checklist obrigatório.

## Exemplo real — estudo de público-alvo (nicho fitness/performance)

Estudo real completo de persona para um cliente do nicho fitness (academia/suplementação/performance). Estrutura de referência para a skill `05-audience-persona-analysis`:

**Segmentos de público:** frequentadores de academia · crossfiteiros · fisiculturistas · atletas · maratonistas (cada um com objetivos específicos diferentes — não tratar como público único).

**Dores mapeadas em 3 camadas:**
- Psicológicas/emocionais: falta de motivação, ansiedade por resultados rápidos, dificuldade de consistência na dieta, pressão estética, baixa autoestima em lesão/estagnação.
- Físicas: cansaço/overtraining, dores musculares, dificuldade de recuperação, distúrbios do sono, problemas intestinais por dieta hiperproteica.
- Financeiras: suplementos caros, personal/nutricionista fora do orçamento, mensalidade de academia alta.

**Objeções reais coletadas** (linguagem literal do público — usar como referência de tom): "Não tenho tempo suficiente pra treinar", "Já tentei antes e não consegui manter", "Suplemento não faz diferença, é marketing", "Minha genética não ajuda".

**Necessidades em 3 camadas:** físicas (performance, massa muscular, energia, recuperação), emocionais (confiança, motivação, pertencimento a uma comunidade), práticas (plano simples, suplemento confiável, apoio profissional, progresso visível).

**Gírias/linguagem do nicho** (exemplo de como capturar vocabulário real da persona): bulking, cutting, pump, shape, trincado, seco, natural, fake natty, drop set — termos que só quem é do nicho usa, e que sinalizam pertencimento quando aparecem na copy.

**Leitura estratégica:** este exemplo mostra o nível de profundidade esperado da skill `05` — não é "público: pessoas que treinam", é a segmentação por perfil (5 sub-públicos com objetivos diferentes) + dor em 3 camadas + objeção na linguagem literal do público + vocabulário de nicho capturado de fóruns/comunidades reais, não inventado.
