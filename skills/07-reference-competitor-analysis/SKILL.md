# Reference & Competitor Analysis

A Thamy trabalha com referência, concorrente, site, Instagram e materiais do cliente antes de escrever. Esta skill formaliza essa etapa.

## Dados necessários

1. Links/referências do briefing (skill `01`) — instagram, site, LP, referência visual obrigatória.
2. `BASE DE CONHECIMENTO/Pinterest - Copywriting Techniques/` — swipe file de imagens de técnicas de copywriting, útil como referência de estrutura visual.
3. `knowledge/exemplos-de-estruturas.md` — contém o template real da V4 para este checkpoint (seção "Template real — Análise de concorrência").
4. Concorrentes mencionados pelo gestor, se houver.

## Checkpoint único — Leitura de referência

Use o template real da V4 (`knowledge/exemplos-de-estruturas.md`):

```
1 - Concorrentes diretos
2 - Concorrentes indiretos

Meta Ads
Análise geral:
Análise de copy:
Visão do anúncio:

3 - Referências de anúncios
```

Complementando, responda — com base no que foi efetivamente fornecido (não invente o que não foi visto):

```
O que aproveitar?
O que evitar?
Qual tom seguir?
Qual estrutura parece funcionar?
Qual tipo de promessa aparece na referência/concorrência?
Qual padrão visual/comercial a referência usa?
Como superar a comunicação genérica (o que a concorrência não está fazendo)?
```

Regra crítica: se nenhuma referência/link foi fornecido no briefing, não invente análise de concorrência fictícia. Diga isso explicitamente e pergunte se o gestor quer indicar concorrentes/referências antes de seguir, ou se prefere seguir sem essa etapa (registrando a ausência).

Se a referência for um formato que você não consegue processar diretamente (ex.: vídeo/áudio), registre a limitação e o proxy usado (ex.: roteiros de texto de campanhas anteriores do mesmo cliente) — isso não precisa gerar uma pausa exclusiva, a menos que a ausência da referência real possa mudar materialmente a estratégia (big idea, ângulo, promessa).

## Modo de operação

- **Estratégico:** apresente a análise isoladamente e pergunte, como abaixo.
- **Rápido/Express:** rode silenciosamente dentro do bloco de pesquisa e leve o resultado (incluindo limitações/proxies registrados e fontes permitidas/excluídas) para o Checkpoint 2 ("Mapa estratégico"). Só pause fora do checkpoint consolidado se a ausência de referência mudar materialmente a estratégia, ou se o gestor pedir para desconsiderar/reconsiderar uma fonte específica.

**Apresente a análise (ou a ausência de material) e pergunte (checkpoint isolado, modo Estratégico; ou dentro do Mapa estratégico, modos Rápido/Express):**
- "Essa leitura de referência está certa? Tem concorrente que eu deveria considerar e não mencionei?"

Aguarde aprovação antes de avançar.

## Auto-validação

- [ ] Não inventou análise de referência que não foi fornecida?
- [ ] Diferenciou claramente "o que aproveitar" de "o que evitar"?
- [ ] Conectou a leitura com a marca/persona já analisadas (skills 03 e 05), não é análise solta?

Se falhou → regenere silenciosamente.
